LLM中的提示词压缩工程#

在自回归LLM中，模型接收提示词并将其映射为词嵌入向量，然后在每一层计算key和value，并存入缓存。然而，当上下文窗口变长时，过长的提示词可能增加计算量，导致模型推理效率下降；也可能“稀释”模型的注意力分配，导致模型输出质量下降。本文将介绍多种常见的提示词压缩方法。 〔1〕 〔2〕

一、压缩对象和预算#

先建立一个整体的认知：记任务指令为 III，上下文或示例为 XXX，当前问题为 qqq，回答为 yyy，⊕\oplus⊕ 表示沿序列维拼接。若只压缩上下文，原始和压缩后的两条计算路径可写为

Pfull(y)=PG(y∣I,X,q),Z=C(X;q),Pcomp(y)=PG(y∣I,Z,q).P_{\rm full}(y)=P_G(y\mid I,X,q),\qquad Z=C(X;q),\qquad P_{\rm comp}(y)=P_G(y\mid I,Z,q).Pfull​(y)=PG​(y∣I,X,q),Z=C(X;q),Pcomp​(y)=PG​(y∣I,Z,q).
  • C(X;q)C(X;q)C(X;q) 可以针对这次问题保留证据；C(X)C(X)C(X) 可以提前为同一文档建立一份表示，随后服务多个问题
  • 设 BBB 为预算、ℓ\ellℓ 为任务损失。目标函数记为 min⁡CE[ℓ(G(I,C(X;q),q),y)]\min_C\mathbb E[\ell(G(I,C(X;q),q),y)]minC​E[ℓ(G(I,C(X;q),q),y)]，约束为 ∣C(X;q)∣≤B|C(X;q)|\le B∣C(X;q)∣≤B。

二、硬提示：Filtering#

1. Selective Context#

原论文图 2。上半部按自信息着色，下半部显示筛选后留下的原文单元。 〔3〕

  • 自信息。 小型因果语言模型在位置 ttt 给词表打分 ztz_tzt​。先归一化 pt(v)=softmax⁡(zt)vp_t(v)=\operatorname{softmax}(z_t)_vpt​(v)=softmax(zt​)v​，再取原文实际出现的 xtx_txt​。它的自信息为 st=−log⁡2pt(xt)s_t=-\log_2 p_t(x_t)st​=−log2​pt​(xt​)。越容易根据前文预测的词，分数越低。
  • 固定一个位置，对词表求期望，得到预测分布的熵；固定一段已经发生的文本，沿位置平均，得到模型在该文本上的平均负对数概率。
H(pt)=∑v∈Vpt(v)[−log⁡2pt(v)],h(X)=1n∑t=1nst,PPL(X)=2h(X).H(p_t)=\sum_{v\in V}p_t(v)[-\log_2p_t(v)],\qquad h(X)=\frac1n\sum_{t=1}^n s_t,\qquad \mathrm{PPL}(X)=2^{h(X)}.H(pt​)=v∈V∑​pt​(v)[−log2​pt​(v)],h(X)=n1​t=1∑n​st​,PPL(X)=2h(X).
  • 可以按 token、短语或句子筛选。对连续单元 u=xa:bu=x_{a:b}u=xa:b​， s(u)=−log⁡2P(xa:b∣x<a)=∑t=absts(u)=-\log_2P(x_{a:b}\mid x_{<a})=\sum_{t=a}^bs_ts(u)=−log2​P(xa:b​∣x<a​)=∑t=ab​st​。短语方案借助句法分析合并名词短语。按单元分数的分位数设阈值，保留高分单元，再按原序拼回。
  • 图中颜色编码自信息，上下两行分别展示原文和筛选结果。每个单元的分数都在原始前文上计算。其中，罕见词可能很意外，得到保留，却与问题无关，这也是Selective Context的缺陷。

2. LLMLingua#

原论文图 1。中间绿色模块依次分配预算、迭代删词；分布对齐作用于小模型。右侧黑盒读取短文本。 〔4〕

  • 粗筛示例。 将提示拆成指令、示例集和问题。小模型计算每条示例的困惑度，按从高到低的顺序在粗筛预算内选入示例。指令和问题通常保留较高比例。
  • 分块细筛。 记第 jjj 块为 SjS_jSj​，前面各块已经保留的部分为 S~<j\widetilde S_{<j}S<j​。该块中第 ttt 个 token 的工作分数可写为
sj,t=−log⁡ps(xj,t∣S~<j,xj,<t),S~j=(xj,t:sj,t≥γj).s_{j,t}=-\log p_s(x_{j,t}\mid\widetilde S_{<j},x_{j,<t}), \qquad \widetilde S_j=(x_{j,t}:s_{j,t}\ge\gamma_j).sj,t​=−logps​(xj,t​∣S<j​,xj,<t​),Sj​=(xj,t​:sj,t​≥γj​).
  • 图中小模型负责打分，黑盒大模型只接收最终文本。论文还用目标模型产生的指令响应数据调整小模型，使打分模型更接近目标模型的分布。
  • 与 Selective Context 的区别。 两者都用原文 token 的预测难度。Selective Context 在完整前文上一次确定单元分数；LLMLingua 增加了分区预算和跨块重打分。它能识别、保护末尾的问题；在通常的前向打分顺序中，较早的文档词仍看不到末尾问题。

3. LongLLMLingua#

原论文图 2。文档重排在粗筛阶段完成，动态预算进入词级细筛；最右侧的子序列恢复位于生成之后。 〔5〕

  • 文档级。 对每篇文档 DkD_kDk​，都让小模型预测同一问题序列 q′q'q′（论文在问题后追加约束语句）。下式越小，读过该文档后，问题越容易预测。
rk=−1∣q′∣∑tlog⁡ps(qt′∣Dk,q<t′).r_k=-\frac1{|q'|}\sum_t\log p_s(q'_t\mid D_k,q'_{<t}).rk​=−∣q′∣1​t∑​logps​(qt′​∣Dk​,q<t′​).
  • 词级。 令 hth_tht​ 表示该处的可用前文。按原论文对数损失的写法，问题为一个已观察词提供的额外信息为
Δt=[−log⁡ps(xt∣ht)]−[−log⁡ps(xt∣q,ht)]=log⁡ps(xt∣q,ht)ps(xt∣ht).\Delta_t=[-\log p_s(x_t\mid h_t)]-[-\log p_s(x_t\mid q,h_t)] =\log\frac{p_s(x_t\mid q,h_t)}{p_s(x_t\mid h_t)}.Δt​=[−logps​(xt​∣ht​)]−[−logps​(xt​∣q,ht​)]=logps​(xt​∣ht​)ps​(xt​∣q,ht​)​.

Δt\Delta_tΔt​ 大，表示给出问题后这个词变得更容易预测，因而得到较高保留优先级。

  • 粗筛后按相关性调整文档位置，减轻关键信息落在长输入中部的影响，并让高相关文档获得较宽松的词级预算。回答生成后，还可以把回答中匹配压缩文本的片段映回原文，以恢复被裁掉的细节。
  • 与 LLMLingua 的区别。 初代给“问题本身”留预算，LongLLMLingua 用“当前问的是什么”决定前面哪篇文档、哪些词值得保留。换一个问题，文档排序和词级保留结果都可能改变。

4. LLMLingua-2#

原论文图 1。左侧教师生成抽取式短文，中间将其对齐成保留标签，右侧学生用一次编码预测各位置的标签。 〔6〕

  • 标签。 让教师模型 GPT-4 对原文执行抽取式压缩，要求尽量使用原词。将短文与原文对齐，给原位置赋保留或删除标签，再做质量过滤。
  • 双向分类。 学生编码器同时读左右上下文。hth_tht​ 为该位置的上下文化表示，yt∈{0,1}y_t\in\{0,1\}yt​∈{0,1} 为对齐标签。二分类头输出保留概率 ata_tat​，以交叉熵训练：
at=softmax⁡(Wht+b)1,L=−∑t{ytlog⁡at+(1−yt)log⁡(1−at)}.a_t=\operatorname{softmax}(Wh_t+b)_1,\qquad \mathcal L=-\sum_t\{y_t\log a_t+(1-y_t)\log(1-a_t)\}.at​=softmax(Wht​+b)1​,L=−t∑​{yt​logat​+(1−yt​)log(1−at​)}.
  • 对一个词的多个子词取保留概率均值，按预算选得分最高的词，再恢复原有顺序。
  • 与前两代的区别。 初代估计“这个词有多难预测”，LongLLMLingua 估计“给出问题后预测这个词改变多少”，LLMLingua-2 估计“教师会不会保留这个词”。最后一种可以在问题出现之前压缩文档，以后反复使用。

5. AdaComp#

原论文图 2。中间横条的切点 K 是预测结果；底部只有前 K 篇文档与问题一起送入生成器。 〔7〕

  • 监督信号。 检索结果已排序为 D1:ND_{1:N}D1:N​。在训练集上，以已知答案 yyy 检查各个前缀。标签是足以使系统答对的最小前缀长度；没有前缀答对时，原算法返回空集。
k∗=min⁡{k∈{1,…,N}:G(q,D1:k) 命中 y}.k^*=\min\{k\in\{1,\dots,N\}:G(q,D_{1:k})\text{ 命中 }y\}.k∗=min{k∈{1,…,N}:G(q,D1:k​) 命中 y}.
  • 预测器以问题和检索集为输入，预测 k^=fθ(q,D1:N)\hat k=f_\theta(q,D_{1:N})k^=fθ​(q,D1:N​)；生成模型读取 q⊕D1:k^q\oplus D_{1:\hat k}q⊕D1:k^​。
  • 与 LongLLMLingua 的区别。 两者都关心当前问题。AdaComp 学的是排序切点，整篇保留入选文档；LongLLMLingua 还可以重排并在文档内部删词。因此相同的 k^\hat kk^ 能产生完全不同的 token 成本，排序靠后的关键证据也可能被前缀选择漏掉。

三、硬提示：Paraphrasing#

6. Nano-Capsulator#

原论文图 2。左侧比较复述和概括的语义，右侧冻结模型对两份提示作答，中间反馈两条答题路径的差异。 〔8〕

  • 压缩器的比较。 可训练模型 FθF_\thetaFθ​ 在复述指令下读取长提示 KKK，得到表示 eKe_KeK​；在概括指令下生成短提示 CCC，得到表示 eCe_CeC​。用均方误差约束两种表示的距离。
  • 冻结模型的比较。 抽取训练问题 qqq，让已有的下游模型 GGG 分别在 K⊕qK\oplus qK⊕q 与 Φ(C)⊕q\Phi(C)\oplus qΦ(C)⊕q 下作答。Φ\PhiΦ 将短提示截到目标预算；比较两条答题路径的隐藏表示，得到论文称为 reward 的效用差异信号。复述和概括分支在 FθF_\thetaFθ​ 上，答题分支在冻结的 GGG 上。
Lsem=EC MSE(eK,eC),Rcap=Eq MSE(hG(K,q),hG(Φ(C),q)),LNano=Lsem Rcap.\mathcal L_{\rm sem}=\mathbb E_C\,\mathrm{MSE}(e_K,e_C),\qquad R_{\rm cap}=\mathbb E_q\,\mathrm{MSE}\big(h_G(K,q),h_G(\Phi(C),q)\big), \qquad \mathcal L_{\rm Nano}=\mathcal L_{\rm sem}\,R_{\rm cap}.Lsem​=EC​MSE(eK​,eC​),Rcap​=Eq​MSE(hG​(K,q),hG​(Φ(C),q)),LNano​=Lsem​Rcap​.
  • 与 LLMLingua-2 的区别。 抽取器只能从原文词序列中选择；生成式压缩器可以合并、换词和重组句子。后者有机会保留跨句含义，也增加逐步生成短文的开销及改写事实的可能。

7. CompAct#

原论文图 2。每列是一轮读取。前一列的短文本进入后一列；下方的判断由证据不足转为充分时终止。 〔9〕

  • 状态。 将检索文档分批为 B1,…,BJB_1,\dots,B_JB1​,…,BJ​。初始摘要 C0C_0C0​ 为空；每次把问题、上一版摘要和新一批文档交给压缩器。图中从第二轮起才出现“Previous Output”。
(Cj,Ej)=Fθ(q,Cj−1,Bj),j∗=min⁡{j:Ej 判断证据充分};y^=G(q,Cj∗).(C_j,E_j)=F_\theta(q,C_{j-1},B_j),\qquad j^*=\min\{j:E_j\text{ 判断证据充分}\}; \qquad \hat y=G(q,C_{j^*}).(Cj​,Ej​)=Fθ​(q,Cj−1​,Bj​),j∗=min{j:Ej​ 判断证据充分};y^​=G(q,Cj∗​).
  • 停止条件。 EjE_jEj​ 给出判断理由和结论。证据不足则读下一批，证据充分则提前停止；若始终不充分，读完末批后使用最终摘要。早先文档中的中间事实只能通过 Cj−1C_{j-1}Cj−1​ 传给下一轮。
  • 用含逐轮摘要和充分性判断的监督数据微调压缩器。多跳问题受益于跨批合并；若过早判定充分，尚在后续批次的证据没有补入机会。
  • 与 Nano-Capsulator、AdaComp 的区别。 Nano-Capsulator 为长提示学习可复用的短表述；CompAct 围绕当前问题反复更新摘要。AdaComp 通过预测篇数决定读多少，CompAct 通过已经积累的证据决定是否继续读。

8. FAVICOMP#

原论文图 1。下路使目标模型参与证据压缩。图中的日期差异展示了只有压缩器参与和两模型共同参与时可能产生的不同表述。 〔10〕

  • 压缩模型 PcP_cPc​ 读取问题、检索证据 DDD 和摘要前缀 c<tc_{<t}c<t​。目标模型 PgP_gPg​ 只读问题和同一个前缀，根据自身知识预测对答题有用的下一个词。
  • 逐词合并。 每一步在两者共享的词表中选择
ct=arg⁡max⁡v∈V[(1−α)log⁡Pc(v∣D,q,c<t)+αlog⁡Pg(v∣q,c<t)].c_t=\arg\max_{v\in V} \left[(1-\alpha)\log P_c(v\mid D,q,c_{<t}) +\alpha\log P_g(v\mid q,c_{<t})\right].ct​=argv∈Vmax​[(1−α)logPc​(v∣D,q,c<t​)+αlogPg​(v∣q,c<t​)].

这相当于最大化两项概率的加权几何平均。α=0\alpha=0α=0 时完全依赖证据压缩器；增大 α\alphaα 会让目标模型较熟悉的表达更容易入选，也可能加大其已有知识与新证据冲突时的偏移。

  • 与 CompAct 的区别。 CompAct 的决策发生在批次之间，决定要不要继续读；FAVICOMP 的决策发生在摘要的每个生成位置，决定怎样写。原方案是免训练的解码策略，但需要能对齐两个模型的候选 token 并取得相应分数。

四、软提示#

9. Contrastive Conditioning（CC）#

原论文图 1。左右使用同一语言模型；中间的 KL 比较硬前缀和短软前缀所诱导的后续分布。 〔11〕

  • 记当前用户输入及已生成历史为 hhh。实践者另外准备体现目标属性的前缀 x+x^+x+ 和对照前缀 x−x^-x−。“正、负”由希望控制的属性定义。普通对话只有 hhh 时，模型没有这两段材料，也没有自动决定控制方向的步骤。
  • 对给定硬提示 xxx，冻结语言模型，初始化 Sx∈Rk×dS_x\in\mathbb R^{k\times d}Sx​∈Rk×d。让同一模型分别读取硬前缀和软前缀，在相同的训练文本位置比较下一词分布。用统一记号展开图中的 KL 目标：
Sx∗=arg⁡min⁡S Eu∑tDKL ⁣(PG(⋅∣x,u<t) ∥ PG(⋅∣S,u<t)).S_x^*=\arg\min_S\ \mathbb E_{u} \sum_t D_{\rm KL}\!\left(P_G(\cdot\mid x,u_{<t})\,\Vert\,P_G(\cdot\mid S,u_{<t})\right).Sx∗​=argSmin​ Eu​t∑​DKL​(PG​(⋅∣x,u<t​)∥PG​(⋅∣S,u<t​)).

训练文本提供各种后续语境，优化变量是 SSS。每个新的固定前缀都要单独拟合；反复使用同一前缀时可以摊薄训练成本。

  • 分别为 x+,x−x^+,x^-x+,x− 学得 S+,S−S^+,S^-S+,S−。对候选 token vvv，令 p0=PG(v∣h)p_0=P_G(v\mid h)p0​=PG​(v∣h)、p+=PG(v∣S+,h)p_+=P_G(v\mid S^+,h)p+​=PG​(v∣S+,h)、p−=PG(v∣S−,h)p_-=P_G(v\mid S^-,h)p−​=PG​(v∣S−,h)。原论文将属性分数乘回基础分布，并在词表上归一化：
Pctrl(v∣h)=1Z(h)p0(p+p++p−)ω.P_{\rm ctrl}(v\mid h)= \frac{1}{Z(h)}p_0\left(\frac{p_+}{p_++p_-}\right)^{\omega}.Pctrl​(v∣h)=Z(h)1​p0​(p+​+p−​p+​​)ω.
  • 压缩。 用户历史 hhh 在三个分支中都保留；缩短的是两段反复使用的控制示例。ω=0\omega=0ω=0 恢复基础分布。与 LongLLMLingua 对照，后者的对比分数决定删哪个输入词；这里的对比分数调整哪个输出词更可能被生成。

10. GIST#

原论文图 2。逐行读掩码：绿色表示采用 gist 掩码后仍可关注的位置，灰色表示普通模型原本可见、采用 gist 掩码后被阻断的位置。左边是因果解码器，右边分别画出编码器和交叉注意力。 〔12〕

  • 构造序列。 令 TTT 为指令、g1:kg_{1:k}g1:k​ 为追加的 gist 位置、XXX 为本次输入。模型处理 [T;g1:k;X;y][T;g_{1:k};X;y][T;g1:k​;X;y]。相同的特殊 token 在不同指令后会产生不同状态，因为它们在计算注意力时读到了不同的 TTT。
  • 在 decoder-only 实现中，对查询位置 iii 与键位置 jjj，可将加性掩码写成
Aij={−∞,j>i,−∞,i∈X∪y, j∈T,0,其余情况.A_{ij}=\begin{cases} -\infty,&j>i,\\ -\infty,&i\in X\cup y,\ j\in T,\\ 0,&\text{其余情况}. \end{cases}Aij​=⎩⎨⎧​−∞,−∞,0,​j>i,i∈X∪y, j∈T,其余情况.​

gist 位置可以读指令，输入与回答位置可以读 gist 和各自可见的历史。若放开 X→TX\to TX→T，模型就能绕过 gist，保留原指令也会成为推理时的依赖。

  • 训练和复用。 在多种指令、输入与目标回答上训练带掩码的模型。遇到新指令时一次前向即可形成 gist；相同指令换输入时可直接复用 gist 状态。在因果模型里缓存相应位置的逐层 KV，随后无需保留全部指令位置。
  • 与 CC 的区别。 CC 为每条固定前缀重新优化矩阵；GIST 将“怎样读出指令摘要”学进模型参数，因此能够对训练时未见的指令执行压缩。

11. AutoCompressor#

原论文图 1。自下而上是相继读入的文本段。段末摘要沿箭头传给后续段；顶部紫色框为累积的摘要向量。 〔13〕

  • 分块读。 将长文分成 S1,…,SJS_1,\ldots,S_JS1​,…,SJ​，每段末尾追加 kkk 个摘要位置。记 UjU_jUj​ 为本段摘要，U<jU_{<j}U<j​ 为以前各段摘要的拼接。论文的摘要累积版本可写为
Uj=tail⁡kFθ ⁣(U<j⊕E(Sj)⊕E(σ1:k)),U≤j=U<j⊕Uj.U_j=\operatorname{tail}_k F_\theta\!\left(U_{<j}\oplus E(S_j)\oplus E(\sigma_{1:k})\right),\qquad U_{\le j}=U_{<j}\oplus U_j.Uj​=tailk​Fθ​(U<j​⊕E(Sj​)⊕E(σ1:k​)),U≤j​=U<j​⊕Uj​.
  • 下一段只能通过 U≤jU_{\le j}U≤j​ 获取早先文本。用语言建模损失 L=−∑j,tlog⁡Pθ(sj,t∣U<j,sj,<t)\mathcal L=-\sum_{j,t}\log P_\theta(s_{j,t}\mid U_{<j},s_{j,<t})L=−∑j,t​logPθ​(sj,t​∣U<j​,sj,<t​) 训练；后文若依赖前文，被保留的摘要应提高对后文的预测概率。
  • 段末输出取顶层向量，作为下一段输入端的软提示。累积版本的摘要长度随段数增长为 JkJkJk；早先的正文位置不再进入下一段。
  • 与 GIST 的区别。 “逐段做 gist 再拼接”能描述段末读出的直觉。实现上，AutoCompressor 把向量送回输入层、递归处理后续段，并用后文的预测损失训练。GIST 的典型任务是用受限可见性的少数位置承载一条指令，再对新输入执行它。

12. ICAE#

原论文图 3。下方启用 LoRA 的编码端输出记忆槽，上方冻结解码端以这些槽和已知目标前缀逐词重建。 〔14〕

  • 编码。 长度为 nnn 的正文后追加 kkk 个记忆 token，用带 LoRA 的语言模型处理。只取末尾位置的顶层隐藏状态：
M=tail⁡kFθ+ΔLoRA(E(X)⊕Em)∈Rk×d.M=\operatorname{tail}_k F_{\theta+\Delta_{\rm LoRA}} (E(X)\oplus E_m)\in\mathbb R^{k\times d}.M=tailk​Fθ+ΔLoRA​​(E(X)⊕Em​)∈Rk×d.

EmE_mEm​ 是可学习的初始记忆嵌入，MMM 是读完这条正文后的结果。同一组 EmE_mEm​ 可以处理不同文档，每篇得到自己的 MMM。

  • 训练目标。 设 NLLG(b∣a)=−∑tlog⁡PG(bt∣a,b<t)\mathrm{NLL}_G(b\mid a)=-\sum_t\log P_G(b_t\mid a,b_{<t})NLLG​(b∣a)=−∑t​logPG​(bt​∣a,b<t​)。下表给出编码端收到的三类监督：

  • 训练时，在预测 xtx_txt​ 的位置只提供真实前缀 x<tx_{<t}x<t​。标签是原文 token，不需要人为指定“正确的记忆向量”。解码器权重冻结，但损失对输入 MMM 可微，梯度沿 ∂L/∂M\partial\mathcal L/\partial M∂L/∂M 更新编码端 LoRA 和记忆嵌入。
  • 与 AutoCompressor 的区别。 两者的底层都可以采用因果 Transformer。“编码器—解码器”在 ICAE 里指功能分工：编码端学习怎样写入 MMM，原始冻结模型负责读取。AutoCompressor 让同一套经训练的模型递归写摘要、读摘要、预测后文。两者最后都能拼接 embedding，训练约束却不同。

13. 500xCompressor#

原论文图 2。三栏依次展示重建、问答微调和推理。绿色块表示传给冻结解码器的键值状态。 〔15〕

  • 编码前半段类似 ICAE。 将 kkk 个压缩位置追加在正文末尾。区别出现在读出时：对第 ℓ\ellℓ 层，只截取这些位置的键和值。若省略批次维，模型有 LLL 层、HkvH_{\rm kv}Hkv​ 个 KV 头，每头宽度为 dhd_hdh​，则
KX={(Kc(ℓ),Vc(ℓ)):ℓ=1,…,L},Kc(ℓ),Vc(ℓ)∈RHkv×k×dh.\mathcal K_X=\{(K_c^{(\ell)},V_c^{(\ell)}):\ell=1,\dots,L\},\qquad K_c^{(\ell)},V_c^{(\ell)}\in\mathbb R^{H_{\rm kv}\times k\times d_h}.KX​={(Kc(ℓ)​,Vc(ℓ)​):ℓ=1,…,L},Kc(ℓ)​,Vc(ℓ)​∈RHkv​×k×dh​.
  • 标准注意力先从进入本层的状态投影出 Q、K、V，再按注意力权重读取前文。第一层末尾位置在完成注意力后才获得上下文化的输出；上层可将这部分文档信息写进该位置的 K、V。保存所有层，解码器每层就能读取与本层对应的前缀状态。
  • 解码接口。 解码问题时，每层将 Kc(ℓ)K_c^{(\ell)}Kc(ℓ)​ 与当前问题前缀的键沿序列维拼接，值同理。问题的查询与这些键计算注意力，再加权读取值。编码器学习写入缓存，解码器保持冻结。
  • 与 ICAE 的区别。 ICAE 传递 kdkdkd 个输入嵌入分量，解码器自行算出各层 KV；这里直接传递 2LkHkvdh2LkH_{\rm kv}d_h2LkHkv​dh​ 个分量。同样的 k=1k=1k=1，两种方案暴露给解码器的信息接口和离线存储量都不同。

14. xRAG#

原论文图 2。数据库里的文档向量经投影进入语言模型。虚线框中的传统路径需要取回并编码文档文本。 〔16〕

  • 索引阶段。 冻结检索编码器 RRR 将每段文档变成向量 eD=R(D)∈Rdre_D=R(D)\in\mathbb R^{d_r}eD​=R(D)∈Rdr​。它原本用于检索相关文档，适合离线计算和保存。
  • 回答阶段。 找到文档后，训练过的两层 MLP 将它的检索向量映为一个输入 embedding。单篇文档对应一行：
zD=W2σ(W1eD+b1)+b2∈Rd,P(y∣D,q)≈PG(y∣zD⊕E(q)).z_D=W_2\sigma(W_1e_D+b_1)+b_2\in\mathbb R^d,\qquad P(y\mid D,q)\approx P_G(y\mid z_D\oplus E(q)).zD​=W2​σ(W1​eD​+b1​)+b2​∈Rd,P(y∣D,q)≈PG​(y∣zD​⊕E(q)).
  • 检索训练使向量距离有意义；冻结生成模型要求前缀激活能引发合适的回答。即便 dr=dd_r=ddr​=d，维数相同也不能保证这两种用途已经对齐。投影器是两端都冻结后可学习的连接。
  • 先用改述预训练，让模型根据文档向量生成文档文本；随后用上下文感知的指令微调，结合目标答案的语言建模损失与自蒸馏。蒸馏项的方向是 DKL(PG(⋅∣D,q)∥PG(⋅∣zD,q))D_{\rm KL}(P_G(\cdot\mid D,q)\Vert P_G(\cdot\mid z_D,q))DKL​(PG​(⋅∣D,q)∥PG​(⋅∣zD​,q))，完整文本路径提供教师分布。
  • 与 ICAE、500xCompressor 的区别。 xRAG 复用已经存在的检索表示，信息在检索编码器生成单向量时已经收缩。ICAE 用重建与问答监督学习写入多个记忆位置；500xCompressor 还把传递接口推进到解码器每一层。

15. UniICL#

原论文图 2。示例库保存压缩序列；相似度排序决定从库中取哪几条，选中的序列再与问题共同进入生成模型。 〔17〕

  • 设示例 DiD_iDi​ 长 nin_ini​。在末尾追加 kik_iki​ 个共享初始嵌入的记忆位置，冻结的 Vicuna 输出末尾 kik_iki​ 行隐藏状态，再以同一个线性层逐行投影：
Hi=tail⁡kiF(E(Di)⊕[M]ki)∈Rki×d,Ci=HiWp⊤∈Rki×d.H_i=\operatorname{tail}_{k_i}F(E(D_i)\oplus[M]^{k_i}) \in\mathbb R^{k_i\times d},\qquad C_i=H_iW_p^\top\in\mathbb R^{k_i\times d}.Hi​=tailki​​F(E(Di​)⊕[M]ki​)∈Rki​×d,Ci​=Hi​Wp⊤​∈Rki​×d.

长度从 nin_ini​ 缩到 kik_iki​ 发生在取末尾的行。WpW_pWp​ 保留行数，学习把顶层输出对齐到生成模型的输入空间。共享记忆嵌入和投影层都可训练，主干冻结。

  • 候选的 CiC_iCi​ 可预先建库。用同样过程编码新问题，得到 CqC_qCq​。先在单条示例内部沿 token 维平均，再比较余弦相似度：

  • 设选中的示例编号为 i1,…,imi_1,\ldots,i_mi1​,…,im​，解码器读入 Ci1⊕⋯⊕Cim⊕E(q)C_{i_1}\oplus\cdots\oplus C_{i_m}\oplus E(q)Ci1​​⊕⋯⊕Cim​​⊕E(q)，总长度为 ∑jkij+∣q∣\sum_j k_{i_j}+|q|∑j​kij​​+∣q∣。排序阶段的一行均值已完成任务。问题在选示例时压缩过一次，在回答时以完整 token 出现。
  • 首先随机压缩训练输入的一部分，结合剩余原文预测目标答案，训练写入能力。随后用有标签的训练问题测量候选示例的价值：
gi=PPL(y∣q)−PPL(y∣Di,q).g_i=\mathrm{PPL}(y\mid q)-\mathrm{PPL}(y\mid D_i,q).gi​=PPL(y∣q)−PPL(y∣Di​,q).

增益大的候选能让正确答案更容易预测。根据相对增益挖掘正负示例，再结合语言建模与对比训练，使均值向量能区分有益和干扰示例。上线时没有标准答案，用已学到的余弦分数选示例。

  • 与 xRAG 的区别。 两者都把投影结果拼在完整问题之前。xRAG 从一个已有的、固定的文档检索向量出发；UniICL 为带输入和答案的示例生成多行表示，训练共享记忆嵌入来影响读取过程。其均值服务于检索，整组行服务于上下文学习。
